# Refund Payment Funnel Analysis (Python)

**신청 → 결정환급액 → 최종결제** 6개월 전수 데이터를 Python으로 분석해, **아웃바운드 담당자 개입이 실제 결제 성과에 얼마나 기여하는가**를 정량 증명한 프로젝트.

## 문제

세일즈 조직에서 "우리 콜이 실제 매출에 얼마나 기여하는가?" 근거가 부재. VIP 상담과 아웃바운드 중 어느 채널이 효율적인지, 담당자를 붙였을 때와 아닐 때 결제·성사·추심이 얼마나 달라지는지 실측 데이터가 없어 콜 리소스 배분 정책을 감으로 결정하고 있었습니다.

## 지분

**단독**. Python + Pipedrive export · 정제 · 분석 · PDF 생성 전 과정.

## 데이터 규모

- 대상 기간: **2025.07 ~ 12 (6개월)**
- 표본: 신청 완료 **1,008건 / ₩216.3억**
- 대조군: 무담당 **26,671건**

## 분석 축 4개

1. **전환 퍼널**: 신청 → 결정환급액 (건수·금액)
2. **VIP vs 아웃바운드**: 월별 비중·전환율 크로스 분석
3. **결제 시점 분포**: D+0 / D+3 / D+7 / D+30 누적
4. **담당자 유무 정량 효과**: 273건(담당자) vs 26,671건(무담당) 지표 비교

## 결과 (핵심 산출물)

### 담당자 개입 정량 효과

| 지표 | 담당자 있음 (n=273) | 없음 (n=26,671) | 델타 |
|------|-------------------|----------------|------|
| D+3 결제율 | (측정) | (측정) | **+7.2%p** |
| D+30 성사율 | (측정) | (측정) | **+4.0%p** |
| 추심 진행 비율 | (측정) | (측정) | **−4.0%p** |
| 평균 결제 경과일 | (측정) | (측정) | **−1.1일** |

### VIP vs 아웃바운드
- 10~12월 아웃바운드 비율 74~84%
- 아웃바운드 전환율 **22~29%** vs VIP **15~21%** — 아웃바운드가 지속 상회
- → 아웃바운드 확대 정책 근거로 사용

### 결제 시점 분포
- D+0 당일: **38.1%**
- D+7 이내: **83.5%**
- D+30 이내: **91.2%**

## 파이프라인

```
Pipedrive Deal export (3계정: 케어·법인·개인)
    ↓
Google Sheets 정제 (assignee 필드·VIP 태그 그룹화)
    ↓
Python 분석 스크립트
  ├─ 결제 시점 D+N 누적 산출
  ├─ 담당자 유무 대조군 상대 지표(%p)
  └─ VIP vs 아웃바운드 월별 크로스
    ↓
ReportLab PDF 생성 (5개 섹션)
  ① 신청→결정환급액 전환 퍼널
  ② VIP 상담 vs 아웃바운드 전환율 상세
  ③ 최종결제금액 현황
  ④ 결제 시점별 분류 (D+0~30 누적)
  ⑤ 담당자 有/無 비교
```
