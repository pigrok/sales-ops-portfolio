# Refund Payment Funnel Analysis (Claude-assisted)

Pipedrive 6개월치 신청·결제 데이터를 Claude로 반복 대화 분석해, 담당자 개입이 결제 성과에 미치는 정량 효과를 산출한 분석 프로젝트.

## 문제

아웃바운드 담당자 개입이 실제 결제 성과에 얼마나 기여하는지 실측 근거가 없어, 콜 리소스 배분을 감으로 결정하고 있었습니다.

## 분석 접근

1. Pipedrive에서 신청·결제 딜 6개월치를 CSV로 추출
2. 민감정보 제거 후 Claude에 업로드해 담당자 개입군·비개입군 그룹 분리
3. 그룹별 결제율·성사율·추심 비율·결제 경과일을 반복 프롬프트로 비교
4. 결제 시점 분포(D+0 / D+3 / D+7 / D+30) 누적 곡선 도출
5. VIP vs 아웃바운드 월별 비교로 정책 시나리오 검토

## 분석 축

1. 신청 → 결제 퍼널 (건수·금액)
2. VIP vs 아웃바운드 월별 비교
3. 결제 시점 분포 (D+0 / D+3 / D+7 / D+30 누적)
4. 담당자 유무 정량 효과 (핵심 산출물)

## 스택

Claude (대화형 데이터 분석) · Pipedrive export (CSV) · Google Sheets (중간 정제)

## 결과

- 신청→결제 퍼널 **1,008건 / 조회환급액 기준 216억 원** 전수 분석
- 담당자 개입 시 **D+3 결제율 +7.2%p**, 성사율 **+4.0%p**, 추심 **−4.0%p**, 결제 경과일 **−1.1일** 확인
- 콜 리소스 배분 정책 검토의 실측 근거로 활용
