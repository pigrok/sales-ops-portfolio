# Refund Payment Funnel Analysis (Python)

Pipedrive export 6개월치를 Python으로 전수 분석해 담당자 개입이 결제 성과에 미치는 정량 효과를 산출한 분석 프로젝트.

## 문제
아웃바운드 담당자 개입이 실제 결제 성과에 얼마나 기여하는지 실측 근거가 없어, 콜 리소스 배분을 감으로 결정하고 있었습니다.

## 분석 축
1. 신청 → 결정환급액 전환 퍼널 (건수·금액)
2. VIP vs 아웃바운드 월별 비교
3. 결제 시점 분포 (D+0 / D+3 / D+7 / D+30 누적)
4. 담당자 유무 정량 효과 (핵심 산출물)

## 스택
Python · Pandas · ReportLab (PDF 자동 생성) · Google Sheets (중간 정제)

## 파일
- `analysis.py` — 전수 분석 스크립트
- 원본 Pipedrive export는 회사 자산이므로 저장소 미포함, 로컬 경로 참조만 남김

## 결과
- 신청→결제 퍼널 **1,008건 / 조회환급액 기준 216억 원** 전수 분석
- 담당자 개입 시 **D+3 결제율 +7.2%p**, 성사율 **+4.0%p**, 추심 **−4.0%p**, 결제 경과일 **−1.1일** 확인
- 콜 리소스 배분 정책 검토의 실측 근거로 활용
